    FAQ

    Questions the raccoon gets a lot.

    Short answers about what RUMZO reads, saves, and intentionally leaves alone.

    What does RUMZO inspect?+

    It inspects public GitHub repository evidence and supported pons v2 contract settings on Robinhood Chain. The receipt includes direct source links wherever a value is known.

    Does it connect to my wallet or execute trades?+

    No. RUMZO is read-only. It has no wallet connection, signer, transaction path, or trade execution.

    Is a receipt a safety score or endorsement?+

    No. A receipt records observable evidence and coverage limits. It does not decide whether a project is safe, legitimate, or worth buying.

    Where are my saved receipts stored?+

    They stay in this browser on this device. You can also download each receipt as JSON or Markdown.

    Does monitoring continue after I close the site?+

    The website checks due projects while the page is open. For unattended schedules and Telegram alerts, run the open-source local monitor on a computer or server you control.

    Why can some fields be unavailable?+

    A repository may be private, a provider may limit requests, or a contract may not expose a supported field. RUMZO labels those gaps rather than treating missing data as proof.

    Can I inspect the code behind RUMZO?+

    Yes. RUMZO is open source. Read the implementation, run it locally, or open an issue on GitHub.
