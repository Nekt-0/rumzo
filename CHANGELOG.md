# Changelog

## 0.3.0

- Added persistent browser and local watchlists with six bounded inspection intervals.
- Added scheduled re-inspection, receipt timeline events, pause/resume controls and manual checks.
- Added explicit code, contract, combined, coverage, stable and failure event states.
- Added an unattended local monitor runner and optional Telegram change notifications.
- Updated the public interface for the v0.3 monitoring workflow while keeping all receipt data device-local.

## 0.2.0

- Added a public Worker build with live read-only GitHub and Robinhood Chain inspection.
- Moved hosted receipt history and comparisons into each visitor's browser.
- Added a production bundle check and browser-side JSON and Markdown exports.

## 0.1.0

- Public GitHub inspection pinned to a commit, with explicit file-tree coverage.
- Read-only pons v2 contract observations pinned to a Robinhood Chain block.
- Local web app and CLI, snapshot storage, comparisons, JSON and Markdown export.
- Isolated synthetic walkthrough and reproducible demo export files.
- Dedicated modules for providers, reports, storage and HTTP serving.
- Focused test suites, original PNG/SVG assets and real application screenshots.
