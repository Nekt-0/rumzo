# RUMZO identity

RUMZO is a skeptical, curious raccoon who asks to see the receipts.

- Name: **RUMZO**; UI wordmark: **rumzo.**
- Main line: **Show the receipts.**
- Product line: **Big claims. Small raccoon.**
- Palette: forest #11150f, pale green #c7e887, warm paper #f3f0e3, ink #26311e.
- Voice: specific observations, clear uncertainty, compact explanations.
